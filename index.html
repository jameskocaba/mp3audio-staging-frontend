How to Record Streamed Tracks in Your Browser

  1. Open your music stream in another browser tab (Spotify Web, SoundCloud, Bandcamp, YouTube, Mixcloud, web radio, etc.).
  2. Click "Capture Tab / System Audio" in MP3aud.io Studio.
  3. In the browser picker, select that tab (or Entire Screen on Windows/ChromeOS) and make sure "Share tab audio" (or "Share system audio") is checked.
  4. Press Play in your streaming tab. Keep Monitor OFF here so you don't hear double audio.
  5. MP3aud.io records crisp stereo PCM locally in RAM, watches for quiet gaps between tracks to auto-split them, and lets you edit waveforms or save MP3/WAV files straight to a folder on your hard drive.

About MP3aud.io Browser Studio

MP3aud.io is a 100% browser-based audio stream recorder and Audacity-style stereo waveform workstation. Every bit of capture, waveform visualization, silence detection, DSP editing, ID3 tagging, and MP3/WAV encoding runs locally on your machine using Web Audio API, AudioWorklet, Web Workers, and the File System Access API—with no software installation and no server uploads.

Privacy Policy

MP3aud.io processes all audio entirely inside your browser's local memory. Your recordings, imported audio files, cover artwork, and folder selections never leave your computer and are never uploaded to any server. Saving directly to your hard drive uses your browser's permission-gated File System Access API or standard local file downloads.
